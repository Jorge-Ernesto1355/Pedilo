# Pedilo Design Skill

## Purpose

Use this skill when designing or modifying Pedilo interfaces.

Pedilo is a SaaS platform for entrepreneurs and small businesses to manage digital menus and receive organized orders through WhatsApp.

## Design Principles

- Modern SaaS aesthetic
- Clean and minimal interfaces
- Premium visual hierarchy
- Generous whitespace
- Royal blue as the primary brand color
- Subtle borders and shadows
- Modern typography
- Smooth and purposeful animations
- Mobile-first responsive design
- Avoid generic AI-generated UI patterns

## UX Principles

- Prioritize clarity over decoration.
- Keep important actions obvious.
- Minimize unnecessary visual complexity.
- Use consistent spacing and component patterns.
- Provide clear feedback for loading, success, and error states.
- Design specifically for entrepreneurs and small business owners.

## Typography

Prefer modern fonts such as:

- Geist
- Inter Tight
- Manrope
- Sora
- Plus Jakarta Sans

Avoid outdated or overly generic typography.

## Colors

Primary brand color:

- Royal blue

Supporting colors:

- White
- Off-white
- Light blue
- Deep navy
- Neutral grays

Use gradients sparingly and intentionally.

## Components

Prefer reusable components for:

- Buttons
- Inputs
- Cards
- Navigation
- Modals
- Alerts
- Forms
- Dashboard elements

## Animation

Use Framer Motion when appropriate.

Animations should be:

- Fast
- Smooth
- Subtle
- Purposeful

Avoid excessive animations or distracting effects.

## Important Rule

When modifying an existing Pedilo interface, preserve the existing functionality and structure unless the task explicitly asks for architectural changes.

Prioritize:

1. Usability
2. Visual hierarchy
3. Consistency
4. Accessibility
5. Performance
6. Visual polish
